Откройте папку проекта, выберите свой Python через `Python: Select Interpreter`.
В терминале из папки проекта:

```powershell

python main.py
```

Исходные CSV должны лежать в папке `data/` рядом с main.py. Пути внутри кода определяются относительно
самого файла, поэтому запуск из другой рабочей папки тоже поддерживается.

## Принятые решения по данным

- Обучающий CSV разделяется на train/val/test примерно 70/15/15 с seed=12
  и стратификацией по isAlive. Отдельный исходный тестовый CSV называется
  external_test: в нём нет ответов.
- Правила top-10 домов и StandardScaler обучаются только на train.
- Popularity: log10(popularity * 200 + 1).
- Culture: полная группировка из вспомогательного ноутбука, затем one-hot.
  Пропуски — culture_no_data, неизвестные названия — Other Nations.
- House: top-10 наиболее частых известных домов из train, остальные — other.
  Пропуски выделяются в house_no_data; категории кодируются через one-hot.
- Age: пропуски заменяются на 0 с отдельным индикатором age_no_data.
  Для Doreah (S.No=1685) и Rhaego (S.No=1869) возраст исправляется на 0,
  годы рождения на 278 и 299, как рекомендовано во вспомогательном ноутбуке.
- Четыре isAlive-признака родственников: 0 вместо пропуска и отдельный индикатор
  пропуска, чтобы отличать неизвестный статус от смерти.
- Title превращается в has_title. Имена родственников и супруга исключаются
  из-за разреженности. DateOfBirth исключается как во многом дублирующий возраст.
- Стандартизируются age_value, numDeadRelations, popularity_log. Бинарные
  признаки и one-hot столбцы остаются в масштабе 0/1.
- S.No и name сохраняются для сопоставления, но **не являются признаками модели**.
  IsAlive — целевая переменная, также не входит в признаки.
